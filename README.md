# Storm Studio Stations

Three 30-minute station rotations for the Laurel High School EL block (grades 9–12, Progressing / ELPA21 Levels 3–4). The theme is hurricanes on the Gulf Coast.

| Station | Skill | What's inside |
|---|---|---|
| 1 | ELPA21 Practice | Listening announcement (device voice), partner speaking task with rubric, sentence builder, school-notice reading item, chart writing task |
| 2 | Making Inferences | Teacher-led lesson (Ms. Rivera), original story, coached questions with staged hints, everyday-inference items, written inference |
| 3 | Complex Sentences | Teacher-led lesson (Mr. Okafor), connector practice, sentence combining with coach check, mini-paragraph |

Every station has its own 30-minute timer, a "Finished early?" challenge, and a teacher coaching guide with an answer key.

**Agenda board:** `agenda.html` is the projector board, with the essential question, objectives, an editable group rotation chart, a 30-minute round timer with chime, and step checklists for each station.

**Open one station directly:** add `#station-1`, `#station-2`, or `#station-3` to the end of the address.

Single-file HTML. No account, no data collected. Student work is saved only on the device.
